An observed BLE 1.5-A trajectory¶

This notebook replays sanitized historical telemetry, not model inference. The underlying local Standard/Medium forecast was real and paid. Executing this notebook makes zero API calls. The case is separate from the hidden Codabench evaluation.

Task text, evidence, outcomes, rationale, request/account IDs and encrypted payloads are withheld. This is an authentic metadata view, not a complete reproducible evidence-bearing trace. The original receipt is not public; its hash is retained for custodial verification.

What actually happened¶

Luna returned an initial belief of 0.88 and requested semantic search. After that evidence, the second validated belief was 0.88 and requested find_model. The controller did not admit a third response and returned the latest model belief. Therefore the last tool result was not incorporated into a later response. This was an intermediate Completion readout, not a native final submit.

Measured time components¶

Initialization is shown separately from the inference window. The residual is elapsed time not attributed by these saved component counters; it is not assigned to a particular subsystem. These are one-case local observations, not a hosted throughput estimate.

What this demonstrates—and what remains unavailable¶

The released metadata records two validated Responses, real local tools, preserved encrypted continuation and a model-derived readout. It does not reproduce the protected prompt, evidence packets, native reasoning or hidden score. Reasoning tokens are a subset of output tokens. Billed cost was not reconciled for this individual historical forecast.
